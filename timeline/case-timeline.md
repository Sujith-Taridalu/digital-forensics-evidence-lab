# Case Timeline

## Reconstructed Activity Window

The investigation identified a concentrated activity window spanning late January through early February 2019.

## Timeline Highlights

- application traces showed use of Discord, Firefox, TrueCrypt, and image steganography tools
- chat-related artifacts suggested suspicious communication and file exchange across that same period
- file and download evidence aligned with the communication trail
- browser activity reinforced interest in concealment, transport, or coordination themes

## Timeline Value

The timeline was useful because it moved the investigation beyond isolated artifacts. It helped show that communication, tool usage, and file activity were related rather than coincidental.
