# Methodology

## Evidence Handling

The disk image was treated as the primary evidence source and analyzed in read-only form. Hash validation was used to confirm integrity before examination began.

## Investigative Workflow

### 1. Hash Validation

The image hash was verified to establish that the evidence had not been altered.

### 2. Image Mounting

The disk image was mounted in a read-only state to preserve evidentiary integrity.

### 3. Application Activity Review

Recently executed application traces were reviewed to identify likely tools and user behavior. Prefetch data was used to surface applications of interest.

### 4. Communication Artifact Review

Recovered Discord cache artifacts and chat-related content were examined to identify communication patterns, shared files, and suspicious coordination.

### 5. File and Browser Review

User folders, downloads, archives, and browsing history were reviewed to identify corroborating artifacts and evidence of concealment.

### 6. Cross-Correlation

The final phase focused on aligning artifacts from different sources into a consistent investigative narrative and timeline.
