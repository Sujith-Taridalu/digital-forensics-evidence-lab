## Rules

Do not upload raw disk images, raw PCAPs, recovered private files, full chat logs, exact personal identifiers, recovered passwords, malware binaries, offensive social-engineering instructions, or full assignment pages.

The safest screenshots are tightly cropped tool views that prove a forensic method, such as hash validation, Prefetch execution traces, sanitized Autopsy tables, or protocol-only Wireshark views.
